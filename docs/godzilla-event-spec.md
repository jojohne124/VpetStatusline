# 期間限定事件：怪獸入侵（哥吉拉）

分支 `event/godzilla`，檔期暫定 **2026-11-05～11-12**（2026-10-28 試做第一版）。

## 需求（使用者原文整理）

- 多一顆事件鈕（位置、形狀待定）
- 第一次會說明（可重看）：怪獸入侵，請與哥吉拉擊退怪獸
- 點事件鈕跳出選單，三關可選，玩法都是手動戰鬥：
  1. 我方 哥吉拉 1954 VS 敵方 3 式機龍，新場景：破敗都市
  2. 我方 哥吉拉 1994 VS 敵方 基多拉 2001，場景：破敗都市
  3. 我方 紅蓮哥吉拉 VS 敵方 戴斯特洛伊亞，新場景：破敗都市 炎上 ver.
- 通關後要有 CLEAR 標示
- 三關全通給獎勵：哥吉拉寶寶（大耳獸出來解說），營地有空位才能領

## 試做版的做法

| 項目 | 做法 | 位置 |
|---|---|---|
| 事件鈕 | 前線控制列「🦖 怪獸入侵」，放在 🎮 小遊戲旁邊；`data-when="gz"`，檔期外整顆不出現。開發版不看檔期、一直有（掛 dev） | `daemon.js` `gzbtn`、`WHEN.gz` |
| 檔期 | `GZ_FROM`／`GZ_TO`（本地時間 11/5 00:00 ～ 11/13 00:00） | `daemon.js` |
| 說明 | 大耳獸對話（`storyOpen`，放舞台下方）；第一次按自動播，選單「📖 說明」重看 | `GZ_INTRO` |
| 選單 | 共用 `#minipick`，一關一列：雙方小圖、名字、場景、出擊鈕；打贏的蓋 CLEAR 章；最下面是獎勵列 | `gzMenu` |
| 戰鬥 | 手動戰鬥跟電腦打（`mbDevStart('gz', 關卡)`，頁面本地跑 duel-sim）。我方固定是那關的哥吉拉，不是前線那隻 | `gzStart` |
| 數值 | 雙方用角色本身的戰力；敵方是頭目 × `boss`（1.15／1.15／1.25） | `GZ_STAGES` |
| 場景 | `ruins`（破敗都市）、`ruinsfire`（炎上）：程式畫的點陣圖；只給事件用，不進一般對戰的隨機場地 | `mbBg`、duel-sim `EVENT_BGS` |
| 通關 | 打贏 → 結算卡寫 STAGE CLEAR、daemon 記 `ranch.gz.clear` | `gzClear` |
| 獎勵 | 三關全通回選單 → 大耳獸講解 → 「帶牠回營地」。營地滿了就說要空位，之後從選單「領取」 | `gzReward`／`gzClaim` |
| 進度 | `ranch.json` 的 `gz: { seen, clear: [3], rewardId }` | `gzProg` |
| dev | `gzDev act=reset`（清進度、收走送的那隻）／`act=clear`（三關直接通關），release 擋掉 | `DEV_ONLY` |

測試：`scripts/test-godzilla.js`（隔離 daemon 走完整流程）。
