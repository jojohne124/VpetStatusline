# 廣場小遊戲：上班快遲到（規格）

> 狀態：**已併入 main（2026-10-27）**，隨下次發版出貨。前線（dev）也能單機玩一週（頁面內嵌 commute-sim）。

## 一、玩法

| # | 項目 | 內容 |
|---|---|---|
| 1 | 形式 | 橫向捲動的機車競速。所有人**同一張地圖、同一條路**，各自的畫面（攝影機跟著自己） |
| 2 | 角色 | vpet 騎機車＋戴安全帽（比照跑車彩蛋的畫法：角色坐在車上，下半身被車身擋住） |
| 3 | 一天 | 遊戲時鐘 **08:58:00 → 09:00:00，實際 2 分鐘**（1:1）。終點是公司，09:00:00 還沒到＝遲到 |
| 4 | 一局 | **五天＝週一到週五**，每天一場。越後面越塞（車多、紅燈長） |
| 5 | 操作 | 角色釘在畫面左邊 30%（加速往前、煞車往後晃 4%），攝影機上下也跟著自己。→ 油門（放掉慢慢減速）、← 煞車（← → 一起＝輕煞；快的時候只按 ← ＝急煞、冒火花；不快就煞到停）、↑↓ 自由上下移動。X／Z、WASD 同。小視窗：按住自己的右／左／上／下 |
| 6 | 車道 | **4 條**。畫面寬 55 點、只顯示自己附近（攝影機上下跟） |
| 7 | 人數 | 一場最多 **4 人** |
| 8 | 離開 | 離開按鈕寫「**不幹了**」 |

## 二、淘汰（當天出局，隔天照常上班）

| 情況 | 判定 |
|---|---|
| 撞到車 | 汽車（短）、貨車（中）、卡車（長）。碰到就出局 |
| **玩家互撞** | **雙方都出局** |
| 闖紅燈 | 紅燈時車頭越過停止線。**有黃燈**，綠轉紅之間來得及煞車 |
| 遲到 | 09:00:00 還沒到公司 |

- **受傷**（撞車、互撞）的人，**安全帽上多一塊繃帶**，一直貼到週五；撞幾次貼幾塊，最多 3 塊。闖紅燈、遲到不貼。
- **新聞走馬燈**（黑色幽默，只寫人數不寫名字）：
  - 撞車：「今日稍早一名／兩名上班族於通勤途中與卡車發生撞擊，不幸……」
  - 互撞：「今日稍早兩名上班族於通勤途中互撞，不幸……」

## 三、地形

- 直路、**紅綠燈路口**、**圓環**。
- 圓環：中央是圓形島，佔掉中間兩條車道；車流分成上下兩路繞過去，旁邊有車從支線匯入。要選邊走、閃匯入的車。
- 紅綠燈時間、來車、地形全部用**同一個亂數種子**：每個人遇到的路況一模一樣，比的是技術不是運氣。
- **人多車少**（2026-10-27）：玩家自己就是障礙物，每多一個人，車距、圓環匯入間隔各多 15%（4 人 = 1.45 倍）。只動車流，地形不變。排行榜不分人數（目標是各人數的準時率差不多）。

## 四、勝負

1. 先比**出勤天數**（五天中準時到公司幾天）。
2. 同天數再比**總通勤時間**（準時那幾天的抵達時間加總，越少越好）。
3. 週五結算，排行榜存在廣場主機（比照下樓梯）。

## 五、架構（比照下樓梯，不卡頓）

| 項目 | 做法 |
|---|---|
| 誰算 | **廣場伺服器統一算**（每房一個遊戲迴圈，20 拍／秒）：車流、紅綠燈、碰撞、互撞全部在伺服器判定，大家看到的一致 |
| 上行 | 只在按鍵**改變**時送（加速／減速／換車道） |
| 下行 | 每拍把全場狀態推給房裡的人（既有的 SSE） |
| 畫面 | 60fps，兩拍之間補間；**自己的機車先動**（本地預測），伺服器結果回來再微調，按下去立刻有反應 |
| 共用模擬 | `src/shared/commute-sim.js`（純函式、整數、決定性），伺服器與測試共用 |
