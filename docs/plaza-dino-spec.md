# 廣場小遊戲：小恐龍跑酷

> 狀態：**試做版（2026-10-20）**：單人＋多人影子都能跑（房間沿用下樓梯，加 `kind: 'dino'`）、排行榜另存 `dino-board.json`。
> 第六節照建議：數值先照草稿（實測後調成起跑 50、上限 110 點/秒，重力 300、起跳 95 —— 草稿的 30 點/秒太慢，
> 一叢仙人掌在物理上跳不過），排行榜分兩份。
> 致敬 Chrome 斷網時的小恐龍：角色一直往右跑，跳過仙人掌、閃過飛鳥，越跑越快，分數是跑了多遠。

| # | 項目 | 決定 |

| 6 | 角色 | 每個人前線的 vpet |
| 7 | 房間、等待面板、排行榜 | 沿用下樓梯那一套（`plaza-stairs-spec.md`），多一種遊戲 |

## 二、架構：位置各自算，伺服器只發 seed、收成績

下樓梯是伺服器統一算（玩家之間會推擠，各算各的會分岔）。小恐龍**不一樣**：

- 玩家之間**沒有互動**（影子不會撞人），各算各的不會出問題。
- 很吃「按跳的那一瞬間」：伺服器算的話按下去要等 50ms 以上才起跳，手感會黏。

| 部分 | 誰算 | 說明 |
|---|---|---|
| 跑動、跳躍、碰撞 | **各自的瀏覽器**，60fps | 按下去當下就起跳 |
| 賽道（障礙物） | **同一個 seed** 產生 | 伺服器出發時發 seed，大家跑同一條 |
| 別人的位置 | 每人約 **100ms** 回報一次（距離、高度、活著沒） | 伺服器轉給同房的人，畫成影子並補間 |
| 撞到、分數 | 各台自己判定後回報 | 內網同事之間先不防作弊 |

所以小恐龍**不需要**伺服器的 50ms 迴圈，也不需要瀏覽器的 50ms 推播：位置回報 10Hz 走既有的 `/stairs/stream` 那條推播就夠。

### 2.1 共用模組

- 新檔 `src/shared/dino-sim.js`：純邏輯（賽道產生、物理、碰撞、計分），**瀏覽器跟測試共用同一份**。
  瀏覽器端由 daemon 把這支內嵌進頁面（跟風的點陣一樣是資料／程式碼，不含 template literal 會出事的字元）。
- 同一個 seed + 同樣的按鍵時間 → 同樣的結果（測試靠它；之後要防作弊也能用重播驗證）。

### 2.2 房間（沿用下樓梯，加一個 `game` 欄位）

| 改動 | 內容 |
|---|---|
| 房間 | 多一個 `game: 'stairs' \| 'dino'`；下樓梯的房間行為不變 |
| 出發 | `dino` 的房間不開伺服器迴圈，只廣播 `{ seed, startAt }`（startAt = 現在 + 倒數 2 秒，用伺服器時間） |
| 回報 | 新端點 `/stairs/report` `{ dist, y, alive }`，伺服器轉成 `dino:ghost` 給同房的人 |
| 結束 | 所有人都撞到（或離開）→ 伺服器排名次、寫排行榜、廣播結果 |
| 排行榜 | 另一個檔 `~/.vpet/dino-board.json`，格式同下樓梯（名牌、角色、分數、日期） |

## 三、玩法

### 3.1 畫面

- 跟廣場畫布一樣大（69 × 54 點），蓋在廣場上；地平線在下方三分之一。
- 自己的 vpet 固定在左邊（x ≈ 8），賽道往左捲。角色大小同下樓梯（12 點）。
- 別人：同一條跑道上的**半透明影子**（50%），頭上小名牌。誰跑得比我遠，影子就在我右邊。
- 右上角：分數（距離，5 位數，像原版 `00123`）＋最高分。

### 3.2 物理與障礙物（數值都是草稿，實作時調）

| 項目 | 草稿 |
|---|---|
| 起跑速度 | 30 點/秒，每 100 分加速一點，上限 70 |
| 跳 | 按下去立刻起跳；按住的話飛高一點（放開就提早下墜） |
| 仙人掌 | 小（4×8 點）、大（6×12 點）；單株或 2～3 株一叢 |
| 飛鳥 | 高、中、低三種高度：低的要跳、高的站著就閃過（**沒有蹲**，所以不出「只有蹲才閃得過」的高度） |
| 間距 | 依速度保證跳得過（不會出現物理上躲不掉的組合） |
| 碰撞 | 用比畫面小一點的身體判定（原版也是，擦邊不算撞） |

### 3.3 結束與分數

- 撞到就停在原地（畫面上倒下來：SAD 幀），影子模式繼續看別人跑。
- 分數 = 距離。全部人都撞到 → 結果：名次、分數、有沒有破紀錄、排行榜前 10，可以再來一局。
