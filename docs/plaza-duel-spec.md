# 廣場：手動戰鬥

> 狀態：**試做版（2026-10-20）**。點別人的 vpet →「🎮 邀請手動戰鬥」，對方接受就直接開打（疊在廣場上，跟小遊戲一樣大）。

## 一、場地與回合

九宮格：A 欄自己（畫面左邊永遠是自己）、B 欄中間（子彈飛過）、C 欄對手；0 上、1 中、2 下。兩邊都從中間那列開始。

每回合雙方**同時**依序選（點格子／按鈕，或 ↑↓ + Enter；Esc 返回上一步）：

| 步驟 | 內容 |
|---|---|
| ① 移動 | 上／不動／下（在邊上只能不動或往中間） |
| ② 攻擊位置 | 對手那欄的上／中／下 |
| ③ 力度 | 來回彈的條，點擊或空白鍵停住。0～80% ×1、80～95% ×1.5、95% 以上 ×2 |

- 時限 **10 秒**（三步加起來）。到了還沒選的部分用預設：不動、打正前方、×1。
- 雙方移動完才發射。猜中對手**移動後**的位置就打中。
- **對波**：雙方都猜中 = 子彈走同一條線、相撞（位置在 B 欄、兩人那兩列的中間）。比實際傷害（攻擊 × 倍率），強的贏、繼續飛打中對方；一樣強兩顆都消掉。所以每回合最多只有一方扣血，不會同時歸零。
- 選了什麼對手看不到（只看得到「對手已選好 ✓」），結算後才演出來。

## 二、數值

戰力 = 廣場對戰用的那個（min(基礎 power + 訓練值, 階級上限)）。

| 項目 | 公式 |
|---|---|
| 血量 | 戰力 |
| 攻擊 | 戰力 / 4，向上取整數（不取到 10 的倍數：低戰力會一下就死、跨門檻會跳一級） |
| 傷害 | 攻擊 × 力度倍率，向上取整數 |

- 血量先歸零的輸。打滿 **20 回合**比剩餘血量，一樣就平手。
- 認輸（右下「🏳 認輸」）、中途離開、斷線超過 3 秒 → 對手贏。
- **不算戰績、不算進化**（跟一般對戰分開，避免拿來刷）。

## 三、演出

| 時間 | 內容 |
|---|---|
| 開場 2.6 秒 | 雙方 cutin 從畫面外滑入（自己左下、對手右上，都面向中間），中間 VS |
| 0～0.4 秒 | 雙方移動（位移動畫） |
| 0.4 秒起 | 攻擊幀、發射子彈（子彈不旋轉，路徑是斜線） |
| 對波 | 子彈在中間邊緣相連、上下錯開抖動 0.8 秒 → 輸的淡出、贏的繼續飛 |
| 打中 | 一般戰鬥那顆爆炸、受傷幀；血條（不顯示數字）這時才扣 |
| 結束 | 勝方開心、敗方難過 → 結果面板 → 回廣場 |

背景隨機三選一（程式畫的點陣）：羅馬競技場、拳擊擂台（看得到四面圍繩，前面那排畫在角色前面）、練舞室。不畫格線，選擇時才把能選的格子框出來。

子彈原圖面左：左邊（往右打）的不翻、右邊的翻。cutin 是左邊的翻、右邊的不翻。

## 四、架構

回合制、不吃時機 → **伺服器判定**（同五子棋，不用輸入同步）：

- 邀請帶 `kind: 'duel'` → 對方接受 → 伺服器開一間 `kind: 'duel'` 的 2 人房，直接 `state: 'play'`（沒有等待畫面，不會出現在小遊戲選單）；兩隻在廣場停在原地、頭上 ⚔。
- `/stairs/dpick { mv, aim, p }`：一回合只收一次，演出中不收；可以只給一部分（沒給的用預設）。兩邊都選好或時限到 → `duel-sim.resolve` 結算 → 推 `duel:round { last }`。
- 房間資料（`roomPub().duel`）只給 `picked`（選好了沒），不給選了什麼。
- 頁面看到新的 `last.round` 就照時間軸演出；`/stairs/dresign` 認輸。

## 五、dev 測試對戰

開發版的小遊戲選單最下面「⚔ 手動戰鬥（dev 測試）」：不經伺服器，同一套 `duel-sim.js` 在頁面本地跑。
對手是**同階隨機一隻**、戰力在那一階（該階最低 power ～ 階級上限）隨機；每回合**隨機移動、隨機攻擊、隨機力度**。release 不給（`duelDev` 在 `DEV_ONLY`）。
