# 廣場小遊戲：五子棋

> 狀態：**試做版（2026-10-20）**。1 對 1，中間是棋盤，兩邊的 vpet 站在左右，隨著棋局做表情。

## 一、玩法

| 項目 | 內容 |
|---|---|
| 人數 | 剛好 2 人（房間上限 2；只有 1 人時出發鈕停用） |
| 棋盤 | 15 路。房主執**黑**先下，加入的人執白 |
| 下子 | 輪到你時點棋盤（滑鼠停的位置有半透明預覽），下在最近的交叉點；最後一手有紅點 |
| 勝負 | 橫、直、斜任一方向**先連成五顆（含以上）**就贏；下滿 225 手平手。沒有禁手 |
| 認輸 | 畫面右下「🏳 認輸」 |
| 中途離開／斷線 | 留下來的人贏（斷線判定 3 秒）；已經分出勝負的照原本的結果 |
| 排行榜 | 不做（選單不放排行榜鈕） |

## 二、表情（伺服器決定，大家看到一樣）

下完一手，看這一手連成幾顆：

| 連成 | 下的人 | 對手 |
|---|---|---|
| 五 | HAPPY（贏了，一直維持） | SAD（輸了，一直維持） |
| 四 | ATTACK（逼對方） | HURT |
| 三 | HAPPY | ANGRY |
| 其他 | 待機 | 待機 |

表情維持約 2 秒，之後回到待機兩幀交替。輪到誰，誰腳下亮一圈。

## 三、架構

輪流下、不吃時機，所以**伺服器判定**（不用輸入同步）：

- `/stairs/gmove { x, y }`：檢查輪到誰、位置合法、那裡沒子 → 下子、算連線長度、決定表情 → 推 `gomoku:move`。
- 棋盤跟著房間資料（`roomPub` 的 `gomoku`：225 字的棋盤字串、輪到誰、最後一手、表情）走 /plaza 輪詢；
  有人下了一手會推 `gmove`，頁面馬上重抓，不用等輪詢。
- 連成五子後留 2.5 秒讓大家看清楚最後一手，再結算、解散房間、回廣場。
- `/stairs/gresign`：認輸。

## 四、檔案

| 檔案 | 內容 |
|---|---|
| `src/daemon/plaza-server.js` | 房間 `kind: 'gomoku'`、`gomokuLine`（連幾顆）、`gomokuExpr`（表情）、下子／認輸／結算 |
| `src/daemon/plaza-client.js` | 新事件 `gomoku:move` |
| `src/daemon/daemon.js` | 選單、等待面板、棋盤畫面、點擊下子、認輸鈕；角色點陣多送 ANGRY 一幀 |
| `scripts/test-gomoku.js` | 連線判定（四個方向、棋盤邊緣、被隔開）、表情規則、輪流、非法位置、勝負、認輸、離開、斷線 |
