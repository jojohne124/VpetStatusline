# 廣場：偷看盤

> 狀態：**後端完成、畫面待定（2026-10-21）**。畫面構圖由使用者提供後再做。

## 一、玩法

- 廣場限定。一顆隱藏按鈕：平常看不到，滑鼠移過去才浮出「🤫」，提示「上班請專心」。
- 按下去：自己的 vpet 從廣場消失，聊天室出現「XXX 不知道躲去哪了...」。
- 本人看到：轉場 → 在廁所看手機，手機上是股票，可以輸入代號查詢（構圖待定）。
- 回座位：聊天室出現「XXX 若無其事地回來了」，vpet 回到廣場（現在走到哪就出現在哪）。

## 二、躲起來期間

| 項目 | 規則 |
|---|---|
| 廣場畫面 | 不畫這隻（名牌、對話泡泡、點擊判定都沒有） |
| 對戰邀請 | 不能邀別人，也不能被邀 |
| 小遊戲 | 不能開房、不能加入 |
| 開心鈕、跑車彩蛋 | 無效 |
| 聊天 | 照常（聊天室看得到字，但沒有泡泡） |
| 能不能躲 | 對戰中、有邀請、在小遊戲房裡不能躲 |
| 斷線 | 照一般斷線；下次進廣場就是正常出現 |

## 三、股票（只做台股）

- 來源：證交所即時看盤的公開接口（`mis.twse.com.tw/stock/api/getStockInfo.jsp`，不用金鑰）。上市、上櫃一次一起問。
- 全部由 plaza-host 代查：

| 項目 | 規則 |
|---|---|
| 玩家查新代號 | 要先躲起來；**每人 1 分鐘一次**。代號格式不對、查不到的不算次數 |
| 代號格式 | 4～6 碼數字，可帶一個英文字尾（00631L） |
| 快取 | 同一檔 30 秒內再查，用快取，不打證交所 |
| 盤中自動更新 | **每 30 秒一次**，把大家正在看的代號合併成**一個請求**，推給在看的人 |
| 非交易時間 | 平日 09:00–13:30（多留 5 分鐘）以外、週末：不自動更新，只顯示最後一筆 |
| 失敗 | 放慢：30 秒 → 1 分 → 2 分 … 最多 5 分；成功一次就回到 30 秒 |
| 同時請求 | 同一時間只有一個請求在飛（排隊） |

- 回傳欄位：名稱、上市／上櫃、成交價（這一刻沒成交用最佳買價頂著）、昨收、開高低、漲跌與漲跌幅、累積成交量（張）、五檔買賣價、時間。
- 前提：plaza-host 那台要能連外網（2026-10-21 在現在的主機上用 node 測過可以；curl 會被公司的 SSL 檢查擋，node 不會）。

## 四、介面

| 端點／指令 | 內容 |
|---|---|
| `POST /hide { id, hidden }` | 躲起來（預設）／`hidden:false` 回座位 |
| `POST /stock/query { id, code }` | 查一檔；回 `{ quote, at, trading }`，被擋回 `wait`（還要等幾秒） |
| 事件 `stock` | 盤中更新推給在看的人 |
| daemon 指令 | `plazaHide { on }`、`stockQuery { code }`；`/plaza` 多帶 `hidden`、`stock` |
