# 廣場小遊戲：打排球

> 狀態：**試做版（2026-10-20）**。致敬《皮卡丘打排球》：1 對 1，把球打到對面落地就得分，先拿 7 分贏。
> 角色是兩個人各自前線的 vpet，**擊球時用攻擊幀（ATTACK）**。

## 一、玩法

| 項目 | 內容 |
|---|---|
| 人數 | **剛好 2 人**（房間上限 2；只有 1 人時房主的出發鈕停用，顯示「等對手加入…」） |
| 操作 | ← → 或 A D 移動、↑ 或 W 跳、空白鍵／Enter／點畫面 = 殺球鍵 |
| 擊球 | 碰到球就往上彈（左右看碰到身體哪一邊）；擊球後幾格顯示 **ATTACK** 幀 |
| 用力打 | **碰到球的那一刻按著殺球鍵（空白鍵／Enter／點畫面）** → 球速快很多：空中是往對面往下殺，地上是往對面又快又平（2026-10-20，同皮卡丘排球） |
| 網子 | 不能走過網；球從側面撞到網彈回來、掉到網頂往上彈；牆和天花板會反彈 |
| 得分 | 球落在誰那邊，另一邊得分；得分的人發下一球（停 1 秒） |
| 結束 | 先拿 **7 分**贏；贏的開心幀、輸的難過幀。結果面板顯示勝負與比分，回廣場 |
| 中途離開／斷線 | 留下來的人贏（斷線判定同下樓梯：3 秒） |
| 排行榜 | 不做（對戰型，沒有分數可以比；選單上不放排行榜鈕） |

## 二、架構：輸入同步（鎖步）

排球很吃時機（起跳、殺球、救球），伺服器算的話按下去要等一來一回才有反應。所以：

- **兩邊的瀏覽器各算同一套模擬**（`src/shared/volley-sim.js`，原樣內嵌進頁面，同小恐龍的做法）。
  模擬**完全決定性**：全部整數（座標是 1/8 點）、不用亂數、不看時間 —— 一點點不同兩台就會分岔。
- **只交換按鍵**：一格 1/25 秒（同原版）。處理第 f 格時送出第 f+3 格的按鍵（`VB_DELAY = 3`，延遲約 0.12 秒）；
  第 f 格要等「我的、對手的」按鍵都到了才算。網路卡一下畫面會停一下（顯示「等待對手連線…」），但兩邊永遠一樣。
- 伺服器**不算球**：只轉送按鍵（`/stairs/vin` → 對手的 `volley:in`）、收結果（`/stairs/vend`，兩邊算的一樣，誰先報都行）。
- 起跑時間用伺服器時間（倒數 2 秒），兩邊同一刻開始。房間資料帶 `sides`（左、右是誰），左邊是房主。
- 畫面 60fps：在兩格之間補間位置（25 格／秒不補會一頓一頓）。

## 五、跟電腦玩（2026-10-20）

- 選單「🤖 跟電腦玩」：本地跑，電腦是 **Terriermon 助手**，難度先只有「普通」：跑到球後面一點、球低了就跳、在空中多半會殺球，球不在自己這邊就回中間待命。
- 跟電腦玩不走鎖步（不用等網路），我的按鍵當場生效。
- 實作時發現：球正中間碰到會直直往上、落回頭上一直彈（站著不動永遠打不完）→ 一般碰球至少往對面推一點。
