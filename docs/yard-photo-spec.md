# 營地拍照

營地畫面的「📷 拍照」鈕（在圖鑑左邊，只在營地出現；伺服器端就先藏起來，剛打開頁面時前線看不到）。把營地的大家集合到一張照片裡，存成 PNG。

## 流程

1. 按 📷 → 前端換一個 seed，跟伺服器要 `/yard?photo=<seed>`：
   - 一般：大家集合到**一頁**（不管平常是不是兩頁寬）排好站位，每隻隨機擺一個姿勢。
   - 圍爐（春節）：**照原本的座位拍**，只換姿勢。
2. 舞台畫成那個樣子之後，前端把各層（底色、背景、節日、角色、天氣）疊成一張，
   前線那隻從左邊斜 45 度探頭進來 → 快門閃光 → 預覽。
3. 預覽：💾 儲存／🔄 再拍一張（換 seed 重抽姿勢）／關閉（大家回去走）。
   預覽開著時輪詢一直帶同一個 seed，舞台維持拍照的樣子。

空營地、事件（營地第二頁的對峙／戰鬥／結果）進行中不給拍：按鈕停用，伺服器也不理 `photo`。

## 站位與姿勢（`plaza.js`）

- `photoSlots(n, seed)`：**不排成一直線**（2026-10-19：一排一排很呆板）。「最佳候選」取樣：每隻從一批亂數
  位置裡挑分數最高的；擺 12 版挑最好的那版。每隻朝向照片中間。
  - **以靠中央為原則**（2026-10-19 定）：2～6 隻時，離其他人「夠開」（`PHOTO_ROOM`，x、y 取大的 ≥ 17 細格，
    保證不重疊）之後再遠也不加分，改成越靠集合點越好（`PHOTO_PULL`）。集合點 `PHOTO_GATHER` = 照片正中央
    （試過偏向探頭，定案還是正中央）。
  - **盡量不跟探頭重疊、小部分可以**：探頭是 16×16 轉 45 度 = 菱形（`PHOTO_PEEK.r`），用菱形算重疊多深
    （`photoPeekHit`），`PHOTO_PEEK_OK` 細格以內不扣分（擦到邊），再深才扣。
    往中間拉會把大家拉到同一個高度（3 隻最明顯，又變一直線）→ 跟別人高度差不到 `PHOTO_ROW_DY` 的扣分。
  - 7、8 隻（`PHOTO_CROWD`）已經把一頁塞滿，往中間拉只會疊在一起 → 不拉，照舊盡量散開。
  - 5 隻以內不重疊；6～8 隻空間有限，偶爾會稍微碰到。結果只跟 seed 有關（有快取，預覽輪詢不重算）。
- `photoPoses(n, seed)`：開心（HAPPY）／跳＋開心（HAPPY 幀＋跳 4 格）／吃東西（EAT_1）三選一，只跟 seed 有關。
- 站位做法：每隻的可走範圍設成一個點，`posAt` 就一定停在那裡 —— 不必另外寫一套合成。

## 前線探頭（前端 `photoPeek`）

伺服器在 `/yard` 的 `photo.front` 帶前線的點陣（開心幀、面向右、節日配件照穿）。
前端先畫成原尺寸，再整張轉 45 度；`imageSmoothingEnabled=false` = 最近點取樣，保持像素風
（邊緣會有點鋸齒，不會糊）。位置：伺服器的 `PHOTO_PEEK`（左下角），跟站位避開的那塊是同一份，從 `/yard` 的 `photo.peek` 帶給前端。

## 存檔

- `POST /photo { png: dataURL }` → `~/Pictures/vpet/營地-YYYY-MM-DD-HHmmss.png`（沒有 Pictures 就放家目錄的 `vpet`）。
  同一秒存第二張加 `-2`，不覆蓋。只收 PNG，檔名伺服器自己取。測試用 `AGUMON_PHOTO_DIR` 指到暫存目錄。
- `POST /photoOpen { path }`：打開資料夾並選取那張。只開照片資料夾底下的檔。
- 照片要先鋪 `#stage` 的底色：有些背景（聖誕夜空）天空那塊是透明的，靠底色撐著。
